# Query Workflow

Use this workflow when answering questions from project knowledge.

## Steps

1. Read `index.md`.
2. Read relevant canonical claims, source records, and human documentation.
3. Present claim lifecycle, assessment, and freshness separately.
4. Trace evidence and validation results to their recorded origin, locator, binding, validator, and fingerprints.
5. Label inference. Do not treat an LLM summary as evidence for itself.
6. If a durable assertion changes without changing meaning, read its revision and use CAS-protected claim mutation.
7. If meaning changes materially, create a new immutable claim ID and supersede the old claim.
8. Maintain human documentation and `log.md` when required by the session checklist.
